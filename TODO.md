## UI-проб: «глаза» для агента и браузерные smoke-прогоны

**Проблема**: тесты покрывают логику и HTTP-API, но не поведение SPA в
браузере (DOM-гонки, пустые селекты, двойные клики выявлялись только
в реальном использовании). Агент не видит интерфейс.

**Идея**: headless-браузер (Playwright) + скрипт `tools/ui_probe.py`:
поднимает сервер на свободном порту (временная копия `projects/` или
демо-сид), обходит страницы/модалки SPA, сохраняет скриншоты
(агент читает PNG), собирает console-ошибки и упавшие запросы,
падает с ненулевым кодом при ошибках. Возможно: золотые скриншоты
для диффов регрессий, опционально — джоб в CI на теги.

**Составляющие**:

- [ ] `tools/seed_demo.py` (или флаг) — демо-проект с главами,
      глоссарием, логом запусков, чтобы экраны не были пустыми.
- [ ] `tools/ui_probe.py` — обход SPA со скриншотами + console-ошибки.

**Ограничение окружения (Ubuntu, без venv)**: системный Python — PEP 668
(externally-managed), обычный `pip install playwright` не пройдёт.
Кандидаты на решение (решить с пользователем):
`apt install node-playwright` (JS-драйвер — аналог; пакет Python
`python3-playwright` в репо Ubuntu отсутствует), venv/pipx (пользователь
пока не хочет), другое. Зависимость — dev-инструмент, НЕ в
`requirements.txt` проекта; при отсутствии Playwright пробник
деградирует до HTTP-прогона с понятным сообщением.
