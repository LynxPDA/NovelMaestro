## Миграция на внешние библиотеки

Политика (AGENTS.md §2) остаётся «stdlib + минимум зависимостей», но она перестала быть «только stdlib»: библиотека теперь не враг, а инструмент, который обязан (1) иметь fallback или быть обязательным и установлеваемым офлайн из `requirements.txt`, (2) не тянуть за собой сборочных цепочек, (3) не ломать кроссплатформенность. Ниже — итог разбора: что принято, что отклонено и почему.

### Сделано

- [x] **HTTP-транспорт LLM — один, `httpx`.** «Запасной» клиент (`requests`) вычеркнут полностью: второй клиент — это второй адаптер, второй путь обработки ошибок и второй набор тестов ради поведения, которое вызывающий не видит. Один общий `httpx.Client` на процесс даёт переиспользование соединений (конвейер бьёт сотнями запросов в один хост) и раздельные connect/write/read-таймауты.
- [x] **`core/transport.py` — единая точка выхода в сеть.** Контракт один: `open_stream()` → `ResponseStream` (`status_code`, `headers`, `iter_lines()` — байтовые строки SSE без терминатора). Ошибки нормализованы к `TransportError`/`ConnectTimeout`/`ReadTimeout`/`BrokenStream`; гигиена стрима и политика ретраев (H3: только 408/425/429/5xx + Retry-After) живут в `core/common.py` и от бэкенда не зависят. Прямой импорт HTTP-библиотек вне `core/transport.py` запрещён — страж `tests/test_architecture.py` (он же не даёт вернуть второй клиент в pip-список).
- [x] **`.env` читает `python-dotenv`.** Свой парсер был не «25 строк», а собственный диалект синтаксиса. Семантика зафиксирована за библиотекой: `#` вне кавычек — комментарий (значение с решёткой пишется в кавычках, за этим следит `web/api.py::_sanitize_env_value`), `${VAR}` **не** раскрывается (`interpolate=False`), пустое значение — пустая строка. `env_overlay` (окружение > файл) и `WEB_ENV_FILE` из Docker-тома не тронуты.
- [x] **venv как штатный режим разработки: `dev.sh`.** Свежий системный Python обычно PEP 668 («externally-managed») — pip в него не ставит. `./dev.sh setup|deps|test|run|shell|clean`; скрипт активирует окружение, поэтому команды в коде и доках остаются `python3 …` (AGENTS §2). Каталог `.venv` уже был в `.gitignore`.
- [x] **Тесты идут параллельно: 210 с → 3 с.** `./dev.sh test` = `pytest -n auto tests/ -q` (pytest-xdist). герметичность полная: данные в `tmp_path`, тестовые сервера на порту 0, общий клиент транспорта создаётся локально процессу-воркеру. Одиночные прогоны — `./dev.sh test -n 0 tests/test_ner.py`.
- [x] **Тесты в CI** (`.github/workflows/tests.yml`): python 3.11 и 3.12, два профиля зависимостей — `all` (весь стек) и `min` (только обязательный рантайм: regex-фолбэк поиска терминов проверяется постоянно, а не «на машине у разработчика»), плюс проверка совпадения артефактов юзерскриптов со сборкой.
- [x] **`core/deps.py` — реестр зависимостей вместо доки-таблицы.** Роль закрывается любым из её кандидатов; `degraded` = роль на фолбэке (не ошибка, просто медленнее). Активный стек печатается одной строкой в логе сервера при старте и в `python3 -m core.deps` — деградация видна сразу, а не по «почему NER такой медленный».

- [x] **Тесты транспорта** (`tests/test_core_transport.py`): нарезка SSE — в том числе строка, разорванная между чанками, и хвост без `\n`; нормализация ошибок проверяется на настоящих классах исключений httpx; живой раунд-трип и «соединение отвергнуто» идут через stdlib-сервер. Мок LLM в остальных тестах висит на seam `core.transport.open_stream`.
- [x] **Сервер закрыт по мелочам:** `Handler.timeout` (idle-таймаут `IDLE_TIMEOUT_SECONDS` = 300 с) — висящая вкладка больше не держит поток; `daemon_threads = True` — Ctrl-C гасит сервер сразу; `version_string()` — `NovelMaestro/<VERSION>` вместо `Python/3.x`.

### Отклонено (решение осознанное, не «забыли»)

- **tenacity.** Политика ретраев одна и она не про исключения: ретраим по `status_code` из уже открытого стрима и по содержимому (`loop-detected`, `empty`, `cut`, `min_len_ratio`) — см. `stream_chat_completion`. Декоратор с `retry_if_exception_type` описывает другую задачу; ради одной точки вызова он не нужен.
- **psutil.** Снятие дерева процессов закрыто stdlib-кодом (`web/jobs.py::_kill_tree`: POSIX — `killpg` по сессии `start_new_session`, Windows — `taskkill /T`), оно покрыто тестами и платформ не плодит. psutil добавил бы бинарное колесо (C-расширение) и третью ветку остановки в самом чувствительном месте — «нажали стоп, процесс должен умереть».
- **uvicorn / fastapi / ASGI-переписывание.** Сервер синхронный и однопользовательский: SSE-соединений ровно столько, сколько открытых вкладок (единицы), рабочих потоков — десятки, стадии живут отдельными процессами (`JobManager`). Синхронный `ThreadingHTTPServer` + keep-alive (`protocol_version = "HTTP/1.1"`) + `daemon_threads` + idle-таймаут закрывают реальные проблемы; переписывание web-слоя на ASGI — риск против fail-fast и SSE без измеримой выгоды.
- **waitress.** То же: смена одного WSGI-сервера на другой там, где WSGI нет.
- **htmx.** Наш UI — SPA на ванильном JS со своим роутером и `$`-хелперами; htmx — вторая модель DOM-обновлений поверх первой. Локальный файл на 15 КБ против библиотечного слоя в SPA, которую мы сознательно убрали (Alpine удалён).
- **alpinejs-persist (и Alpine в целом).** От Alpine уходили именно из-за реактивности на слушателях; возвращать её вариантом с localStorage-директивой — отменять своё решение. Предпочтения уже лежат в localStorage.
- **dayjs.** Даты в UI форматируются `Intl.DateTimeFormat` (stdlib браузера, локализация бесплатно); отдельная библиотека под `toLocaleString` не нужна.
- **chart.js.** Graph-представления нет: статистика — таблицы и мини-бары на CSS. Библиотека на ~200 КБ ради графиков, которых никто не рисовал.
- **diff-match-patch.** Сравнение глав в редакторе — своя доп. вкладка на LCS по абзацам; diff-match-patch решает другую задачу (семантический diff для LLM) и весит больше, чем весь SPA-код сравнения.
- **tiktoken.** Тянет BPE-словари из сети, ломает офлайн-установку, и точность не нужна: единица размеров запросов — оценка `estimate_tokens` (±20–30%), смысл параметров в ней согласован.
- **pydantic / attrs / dataclasses-фреймворки.** Конфиг — плоский словарь строк из `.env` + argparse; валидация данных стадий — явные проверки с человекочитаемым отказом. Схема-фреймворк добавил бы слой, который надо объяснять, ради 12 ключей.

### Осталось по миграции

Остальное — не «библиотеки», а объём кода: сокращать его дешевле всего общими слоями, а не новыми пакетами.

- [~] **`core/stage.py` — слой стадии: сделано, скрипты мигрированы.** Флаги LLM (имена — контракт `web/stages.py` и форм SPA), резолвер сервера (CLI > `os.environ` > `.env`, `<СТАДИЯ>_*`), `/v1`, форма запроса (`llm_messages` + единственный `stream_chat_completion`), предпросмотр и `Progress` (бар в CLI, `@@PROGRESS@@` в web) описаны один раз; инлайн-копии резолвера из шести скриптов удалены, `cli/` минус 127 строк. Осталось перенести на `stage.complete()`/`Progress` сами тела стадий (сейчас они зовут стрим и `emit_progress` напрямую) и добавить чтение/запись артефактов стадии.
- [x] **`web/api.py` разложен по доменам: 3 084 строки → фасад в 57.** Хендлеры переехали в `api_common.py` (служебное, ctx, кешы, константы, сессия), `api_projects.py`, `api_files.py`, `api_glossary.py`, `api_env.py`, `api_assets.py`, `api_stage.py` и `api_templates.py`. Имена роутов и порядок регистрации (hub → files → m7 → logs → check → templates → jobs) не менялись; тесты и `main.py` продолжают звать `api.<имя>` — фасад реэкспортирует те же объекты, а не копии. Стражи `tests/test_architecture.py`: фасад не обрастает хендлерами, общий mutable-контекст (кеши статистики и опций, `_PREVIEW_STAGES`, логгер) определён ровно один раз.
- [x] **Тесты: скорость набрана параллелизмом, а не «слоем».** Последовательно набор идёт ~3.5 мин, под `pytest -n auto` — ~3 с: герметичность полная (данные в `tmp_path`, сервера на порту 0, LLM замокан на seam `core.stage`), поэтому делить тесты на «быстрые/медленные» и выдумывать инжектируемые часы нечем. `time.sleep` остался только в заглушках стадий (0.02–0.05 с) и в двух тестах остановки/таймаута, которые процессы убивают сразу; одиночный прогон файла — `./dev.sh test -n 0 tests/test_ner.py`.
- [~] **SPA: общие компоненты — слой есть, миграция идёт.** `web/static/ui-components.js`: `h`/`icon` (создание DOM) и каркасы `modal`, `menuButton`, `previewPane`, `listPager`; тесты — `tests/spa/ui-components.test.mjs` (реестр хелперов предпросмотра `UIC.docs`, чтобы модалки не зависели от app.js). Сделано: все view-файлы зовут `UIC.h`/`UIC.iconEl` (свои копии удалены), все 17 оверлеев собираются `UIC.modal` (минус ~1000 строк), тулбарные кнопки-меню — `UIC.menuButton`, оверлей-меню больше не плодят обработчики document и `.open`. Осталось: панели предпросмотра (4 копии редактор+iframe+переключатель) и страницы-таблицы (5 копий пейджера) перевести на `UIC.previewPane`/`UIC.listPager` — компоненты уже реализуют ровно эти сценарии, нужна поштучная переноска вьюх с проверкой пробом.
- [x] **`.sections.json` — атомарная запись.** Все файловые записи общего слоя идут через `core.common.atomic_write` (tmp+`fsync`+`os.replace`): `.sections.json` (плюс временный файл стал уникальным — фиксированное `.tmp` два параллельных запроса затёрли бы друг друга), `source/metadata.yaml`, редактор шаблонов, сид `pdir/.env` при запуске стадии.
