# История версий NovelMaestro

## 0.1.6 (2026-08-31)

### Исправления

- **В Docker LLM-конфиг не доходил до стадий**: в образе файла `.env`
  нет, compose пробрасывает его переменными окружения (`env_file`),
  но `get_server_config`/`get_stage_model` читали только файл —
  стадии получали пустой или «примерный» хост. Теперь приоритет
  `os.environ` > файл (канон §7), и `HOST`/`API_KEY`/`MODEL`,
  а также стадийные `<СТАДИЯ>_*` работают из окружения.
- **Загрузка файлов целиком читалась в память**: multipart-тело
  буферизовалось до парсинга (обход лимита размера). Переписано на
  потоковый разбор с spool-временными файлами и атомарной записью;
  при 400/413 на диск не пишется ничего, имена файлов обрезаются до
  basename, вложенная загрузка в `chapters/...` разрешена.
- **Перезапись файлов при загрузке — без спроса**: если файл в проекте
  уже есть, ранее он молча заменялся. Теперь — модалка с явным
  подтверждением.
- **Гонка в операциях с проектами**: перенос/удаление/переименование
  параллельно (многопоточный web-сервер) могли перемешать состояние
  `.sections.json`; операции с папками проектов — под мьютексом.
- **`copy_project` копировал `.env`**: секреты утекали в копию
  проекта. Теперь `.env` в копиях игнорируется.
- **В Docker терялись наборы шаблонов**: вкладка «Шаблоны» жила
  внутри контейнера и пропадала при пересоздании. Добавлен монтаж
  `./templates:/app/templates`.

### Документация

- `packaging/README.md` → «Обновление»: что переживает обновление
  Docker (projects/templates/job_logs/токен), что нет, вариант
  обновления готового образа через `docker compose pull`.
- Прописано пробрасывание `.env` в Docker (env_file → окружение,
  правки на хосте + `docker compose up -d`).
- Предупреждение: Docker + `WEB_HOST=0.0.0.0` без `WEB_AUTH=1`
  открывает интерфейс всей LAN.

## 0.1.5 (2026-08-31)

### Исправления

- **Дубли и призраки разделов в «Проектах»**: параллельные запросы
  создания раздела (двойной клик по «ОК»; сервер многопоточный)
  проходили проверку «уже существует» вместе и писали раздел в
  `.sections.json` дважды — в списке он появлялся x2, а запись без
  папки на диске оставалась навсегда. Операции со списком разделов
  теперь под мьютексом, `load_sections` схлопывает дубли и
  самолечится (записи без папки игнорируются), кнопка «ОК» модалки
  блокируется на время запроса.
- **Пустые «Раздел» и «Шаблон» при создании проекта**: модалка читала
  разделы/шаблоны из кеша хаба, который сбрасывается операциями с
  разделами — при `null` селекты оставались пустыми, создать проект
  было нельзя. Теперь данные загружаются заново при открытии модалки
  (с сообщением об ошибке, если сервер недоступен).
- **Хаб не обновлялся после изменения разделов**: создание/
  переименование/удаление раздела перерисовывало только модалку,
  страница «Проекты» за ней оставалась старой до перезагрузки.

## 0.1.4 (2026-08-31)

### Исправления

- **Вкладки «Глоссарий» и «Проверка» пустые**: глобал `PAGE_SIZE`
  (размер страницы таблиц) пропал из `app.js` при рефакторинге —
  вкладки падали с `ReferenceError`. Определён локально в
  `project-views.js`, где используется.
- **Новый проект не появлялся до обновления страницы**: `close()`
  модалки создания резолвил промис `false` ещё до окончания загрузок,
  поэтому хаб не перерисовывался. Теперь `close(true)` — сразу после
  создания, опциональные обложка/исходник догружаются фоном.
- **Загрузка исходника в мастере создания**: `POST /api/upload` без
  параметра `project` — файл не загружался; добавлен `?project=…`.

### Сервер

- Адрес по умолчанию — **`127.0.0.1`** (только этот компьютер); для
  доступа с LAN — `--host 0.0.0.0` (тогда рекомендуется `--auth`).
- Порт занят → сервер автоматически берёт следующий свободный
  (`port+1 … port+100`) и показывает фактический адрес в консоли.

### Промпты

- translate/polish поддерживают тег `{original_text}` (как redact);
  тег обязателен — нет тега: предупреждение в лог (один раз на режим),
  текст дописывается после промпта (обратная совместимость убрана).

### Сборка Windows

- `README.txt` переименован в `START.txt` (краткая инструкция по
  запуску; основная документация — `README.md`).

## 0.1.1 (2026-08-29)

Исправления и полировка после первого релиза.

### Исправления

- **Безопасность web-сервера**: отрицательный `Content-Length` больше не
  вешает поток сервера (`read(-1)` ждал EOF) — теперь мгновенный 400;
  раздача статики проверяет путь через `is_relative_to`, а не префиксную
  `startswith` — файл-«сосед» вида `static_evil.txt` больше не отдаётся
  через `GET /../static_evil.txt` (raw-запросы).
- **CI**: к GitHub Release прикрепляется только портативный Windows-пакет
  (zip), без дублирующих артефактов.

### Шаблоны

- NER-промпт: поле `pinyin` заменено на универсальное `reading`
  (произношение), скрипт принимает оба имени поля.
- Отдельные промпты стадий (`translate_prompt.txt`, `redact_prompt.txt`,
  `polish_prompt.txt`) удалены — конвейер использует единый
  `pipeline_prompt.txt` с тегами `<translate>/<redact>/<polish>`.
- Шаблонный `replacements.txt` убран из набора General (правила массовых
  замен — только корневой `replacements.txt.example`).
- `donate.txt` обезличен (личные ссылки заменены плейсхолдерами); единый
  источник — `templates/General/source/donate.txt`.

### Документация

- `help.md` и `DEVELOPERS.md`: раздел «Нюансы промптов» (теги vs файл
  целиком, NER-поля, единый pipeline_prompt.txt), универсальность
  перевода «с любого языка на русский», лог-файл NER.
- `TODO.md` исключён из сборок (docker/robocopy), добавлена инструкция
  по публикации релизов (`packaging/README.md`).
