# 📖 NovelMaestro

**Перевод китайских веб-новелл (zh → ru) с помощью LLM** — но с
человеком в центре: программа автоматизирует рутину (разбор исходника,
глоссарий имён, перевод, проверки, сборку EPUB), а ключевые решения —
выбор промптов, проверка качества, финальная корректура — остаются
за вами.

> Интерфейс — веб-страница в браузере: сервер поднимается одной
> командой, всё управление — мышкой. Никакого программирования.

---

## Возможности

- **Разбор исходника** — EPUB/TXT автоматически превращается в папки глав;
- **Глоссарий имён и терминов** (LLM) — извлечение, проверка, правки с
  подтверждением человеком;
- **Перевод → редактура → полировка** (LLM) — три прохода над каждой
  главой с единым промптом и контекстом;
- **Проверки** — алгоритмическая сверка оригинала и перевода, а также
  LLM-поиск ошибок с review-флоу «принять/отклонить/применить»;
- **Компиляция** — готовые TXT, EPUB и FB2 с обложкой, метаданными и
  страницей поддержки;
- **Wiki** — LLM-компендиум по глоссарию и тексту (в т.ч. в форматах
  для публикации на Rulate);
- **Массовые замены** — регулярные выражения по всем главам без LLM;
- **Шаблоны проектов** — промпты и файлы для разных типов книг.

## Как это устроено

```text
EPUB/TXT → главы → глоссарий → перевод → редактура → полировка
→ проверки → TXT/EPUB/FB2 + Wiki
```

Каждая стадия — карточка с формой на странице «Запуски» проекта.
Между стадиями — человеческие контрольные точки: правки глоссария и
перевода принимает человек, а не машина.

## Быстрый старт

Рекомендуемый способ установки — **виртуальное окружение (venv)**: он
одинаково работает на Windows, macOS и Linux.

```bash
# 1. Создать и активировать venv (Python 3.10+)
python3 -m venv .venv && source .venv/bin/activate   # Linux/macOS
# Windows: py -m venv .venv && .venv\Scripts\activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить web-интерфейс
python3 run.py
```

(на Windows вместо `python3` — `python run.py` или `py run.py`)

Допустимая альтернатива без venv — системный Python (Debian/Ubuntu):

```bash
sudo apt install python3-requests python3-tqdm python3-ahocorasick python3-pytest
```

После запуска откроется браузер с интерфейсом. При первом старте
программа сама создаст папку `projects/` с разделами
**ACTIVE / HOLD / DONE** и шаблоном настроек.

Параметры сервера: `python3 run.py --no-open` (без браузера),
`--projects-dir <путь>` (своя папка проектов), а также
`--host/--port/--auth/--token` — см. `python3 web/main.py --help`.

## Первые шаги

### 1. Создайте проект

Вкладка **«Проекты»** → «＋ Создать новый проект…». Мастер спросит:

1. раздел (по умолчанию ACTIVE);
2. имя проекта (латиницей — имя папки);
3. русское название, автор, жанры — опционально;
4. тип книги — набор промптов (по умолчанию `General`).

Опционально можно сразу загрузить обложку и исходник книги.

### 2. Загрузите исходник

Внутри проекта вкладка **«Файлы»** → «＋ Загрузить»: положите
`.epub` или `.txt` в папку `source/`.

### 3. Запустите конвейер

Кнопка **«▶ Запуски»** в шапке проекта. Карточки идут по порядку:

1. **Разбор исходника на главы** — разбейте книгу на главы
   (режим «По TOC» для epub);
2. **Создание глоссария (LLM)** — извлеките имена и термины;
3. **Проверка глоссария (LLM)** — LLM предложит правки; примите их во
   вкладке «Проверка»;
4. **Перевод (LLM)** — полный цикл: перевод → редактура → полировка;
5. **Проверка перевода** и **Проверка перевода (LLM)** — найдите
   ошибки, примените правки;
6. **Компиляция TXT/EPUB/FB2** — соберите готовый файл;
7. **Создание Wiki (LLM)** — по желанию.

Над каждой карточкой — переключатель **«Простой режим / Экспертный»**:
в простом режиме достаточно нажать «Запустить» — параметры возьмутся
из настроек; экспертный открывает все поля формы.

Во время запуска — живой лог и прогресс; кнопка **«Стоп»** останавливает
работу. История запусков — на «Дашборде» и во вкладке «Логи».

### 4. Правьте тексты

- **Редактор** — главы проекта: оригинал слева, перевод справа,
  подсветка терминов глоссария;
- **Глоссарий** — таблица `ner.json`: правка строк, поиск, экспорт;
- **Проверка** — карточки правок LLM: принять/отклонить/применить;
- **Промпты** — файлы промптов с редактором и предпросмотром.

## Настройка LLM-сервера

Программа работает с любым OpenAI-совместимым сервером (vLLM, Ollama,
LM Studio и т.п.). Подключение задаётся в файле `.env` (шаблон —
`templates/.env.example`) или во вкладке **«Настройки»**:

```ini
HOST=http://localhost:8080/v1
API_KEY=your-api-key
MODEL=название-модели
```

Можно задать отдельный сервер для конкретной стадии: `<СТАДИЯ>_HOST`,
`<СТАДИЯ>_API_KEY`, `<СТАДИЯ>_MODEL` (например `NER_MODEL`,
`WIKI_HOST`). Без `.env` программа не падает — предложит ввести
параметры вручную.

> 🔒 Файлы `.env` содержат ключи и не коммитятся в git.

## Интерфейс

Слева — панель навигации:

- **Дашборд** — сводка по всем проектам и последние запуски;
- **Проекты** — разделы ACTIVE/HOLD/DONE, карточки, управление;
- **Настройки** — системный `.env` и внешний вид;
- **Шаблоны** — наборы промптов и файлов для новых проектов;
- **Заметки** — общие заметки (markdown);
- **Справка** — подробные инструкции по всем разделам программы
  (включая руководство по регулярным выражениям).

Внутри проекта — вкладки: **Файлы, Редактор, Глоссарий, Проверка,
Главы, Статус, Конфиг, Промпты, Логи, Заметки** и страница **Запуски**.

## Зависимости

| Пакет (pip / apt) | Назначение | Обязательность |
| --- | --- | --- |
| `requests` / `python3-requests` | HTTP-запросы к LLM | обязательный |
| `tqdm` / `python3-tqdm` | прогресс-бары | обязательный |
| `pyahocorasick` / `python3-ahocorasick` | быстрый поиск терминов | опциональный (есть regex-fallback) |
| `pytest` / `python3-pytest` | тесты | только для разработки |
