# core/transport.py — единственная точка выхода в сеть (единственный HTTP-клиент)

HTTP-клиент в проекте один — `httpx`, и живёт он **только** здесь: `cli/`, `web/` и `run.py` не импортируют HTTP-библиотеки вовсе (страж `tests/test_architecture.py`; он же не даёт вернуть «запасной» клиент). Запасной не нужен: второй клиент — это второй адаптер, второй путь ошибок и второй набор тестов ради поведения, которое вызывающий не видит. Что даёт общий клиент: переиспользование соединений (конвейер бьёт в один сервер сотнями запросов) и раздельные connect/write/read таймауты.

`open_stream(url, *, headers, payload, connect_timeout, read_timeout)` — единственный способ POST-а в LLM; возвращает контекстный менеджер `ResponseStream`: `status_code`, `headers`, `iter_lines()` (байтовые строки тела по `\n`, `\r` отрезан, пустые строки отдаются как есть — пустая строка SSE = конец события; `[DONE]` и finish_reason видны читателю). Выход из контекста закрывает соединение, в том числе при `break` в середине стрима; запрос уходит на входе в `with`, поэтому «сервер лежит» прилетает именно там и тоже нормализуется.

Ошибки: `TransportError` (базовый) / `ConnectTimeout` (таймаут connect, отказ соединения, недоступен хост) / `ReadTimeout` (сервер молчит в теле; сюда же — нет соединения в пуле) / `BrokenStream` (обрыв тела, битый gzip/декодер). Гигиена стрима и политика ретраев живут в `core/common.py`. Прочее API: `client()` (общий `httpx.Client`), `reset_client()` (сброс — тестам), `BACKEND` (`"httpx"`), `python3 -m core.transport` — сводка.

# core/deps.py — реестр внешних зависимостей (активный стек в лог)

Роль — не имя пакета: роль закрыта, если работает хотя бы один её кандидат; кандидат без модуля — встроенный stdlib-фолбэк, он «установлен» всегда. Роли: HTTP-транспорт LLM (один кандидат `httpx`, обязателен — фолбэка сознательно нет), поиск терминов по главам (pyahocorasick, иначе regex), прогресс-бары CLI (tqdm), тесты (pytest). Только чтение: модуль ничего не устанавливает и поведение не меняет — его выбирают люди и лог.

`ROLES` (роли и кандидаты в порядке предпочтения) / `status()` → строки отчёта `{role, where, required, active, installed, degraded, pip_missing}` (`degraded` — роль на фолбэке: не ошибка, просто медленнее) / `format_status()` — одна строка для баннера/лога (web-сервер пишет её при старте) / `missing_hint()` — что доустановить одним pip-ом / `main()` — таблица для `python3 -m core.deps`.
