# replacements.txt — правила массовых замен для cli/batch_replace.py
#
# Файл скопирован из шаблона General при создании проекта. Заполните
# правила под свою книгу (одна замена на строку):
#
#   ЧТО -> НА ЧТО
#   ЧТО<TAB>НА ЧТО        # табуляция тоже годится
#
#   • пустые строки и строки, начинающиеся с «#», игнорируются;
#   • строки вида «## Заголовок» — секции (заголовок попадает в отчёт);
#   • по умолчанию режим ТОЧНЫЙ (literal): левая часть ищется как обычная
#     подстрока (регистр учитывается, текст сравнивается в NFC);
#   • флаги через пробел в конце строки:
#       |i  — игнорировать регистр;
#       |r  — левая часть = регулярное выражение (re.UNICODE);
#             в правой части работают обратные ссылки \1…\9;
#   • разделитель — ПЕРВОЕ вхождение «->» (или табуляции) в строке;
#   • порядок строк = порядок применения: сначала более специфичные правила.
#
