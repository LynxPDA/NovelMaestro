# tools/ — вспомогательные утилиты

Утилиты вне конвейера NovelMaestro (не `cli/`, не `web/`).

## tampermonkey_rulate_reload.js

Юзерскрипт для браузера (Tampermonkey/Violentmonkey): массовое обновление
переводов глав на **tl.rulate.ru** (и `rulate.ru`) из локального `.txt` —
льёт текст главы и/или меняет название, с паузами, проверкой и dry-run.

### Установка

1. Установите расширение **Tampermonkey** (Chrome/Firefox/Edge).
2. Откройте панель расширения → «Создать новый скрипт».
3. Вставьте содержимое `tools/tampermonkey_rulate_reload.js` целиком
   и сохраните (Ctrl+S).
4. Откройте книгу на Rulate: `https://tl.rulate.ru/book/<id>` — в правом
   нижнем углу появится панель **«RL · обновление глав v2.1»**.

Скрипт работает **от имени вашей учётки** (куки сайта), поэтому перед
использованием залогиньтесь на Rulate в том же браузере.

### Использование

1. Подготовьте `.txt`: каждая глава — заголовок `# [Название :|: Номер]`,
   ниже — текст главы (см. «Формат файла»).
2. «Выбрать .txt» — скрипт разберёт главы, покажет валидные/проблемные
   (дробные номера «Глава 1.5», диапазоны «Глава 1–3» и дубли названий
   внутри файла исключаются из заливки).
3. Настройте: пауза между главами, рандом ±, проверка после записи,
   пропуск совпадающих, fallback по названию, режим названий, диапазон.
4. **dry-run** — прогон без записи (что бы залилось / пропустилось).
5. «Старт» — заливка; «Стоп» — остановка между главами; «Лог» — выгрузка
   лога в `rulate-bulk-log.txt`.

### Формат файла

```text
# [Глава 12 :|: 12]
Текст главы…
вторая строка…

# [Глава 13 :|: 13]
…
```

- Заголовок: `# [` + название + ` :|: ` + номер + `]` — номер после `:|:`
  используется как fallback, если в названии нет `Глава N`.
- Названия вида `Глава 12` распознаются автоматически (номер берётся из
  названия); `Глава 12.5` / `Глава 12–14` — считаются проблемными и
  пропускаются (их нельзя сопоставить одному номеру сайта).
- Текст главы идёт до следующего заголовка (пустые строки схлопываются).

### Сопоставление с сайтом

- По умолчанию глава ищется **по номеру** в оглавлении книги.
- «Title fallback»: если номер не найден — поиск по названию.
- Главы сайта с **идентичными названиями** (дубли) исключаются —
  сопоставление по названию было бы неоднозначным.
- Нестандартные главы сайта (дробные/диапазонные/без номера) не трогаются,
  выводятся в отчёт.

### Настройки

Ключевые дефолты — константа `CFG` в начале файла (можно править до
установки, либо через поля панели):

| Поле панели | CFG | Назначение |
| --- | --- | --- |
| Пауза (мс) | `delayMs: 2100` | задержка между главами (защита от бана) |
| Рандом ± | `jitterMs: 0` | разброс паузы ±N мс (мин. 100) |
| Проверять | `verify: true` | перечитать главу после записи и сверить |
| Пропуск совп. | `skipSame: true` | не лить главы, чьи текст/название уже совпадают |
| Title fallback | `fallbackByTitle: false` | искать главу по названию, если номер не найден |
| Названия глав | `titleMode: 'off'` | `off` / `title-only` (только названия) / `title-and-body` |
| Диапазон | — | `1-50, 55` — заливать только эти номера (пусто = все) |

### Безопасность

- Всегда сначала **dry-run**.
- Скрипт пишет на сайт только ваши переводы (ваши `tr`-фрагменты) и
  обновляет названия через штатные формы редактирования.
- Паузы и рандом — базовая защита от антиспама; для больших книг
  увеличьте `delayMs`.
- Проверка после записи (`verify`) ловит рассинхрон (например, сайт
  нормализовал текст) — такие главы попадают в отчёт как ошибки.
