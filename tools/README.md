# tools — вспомогательные утилиты вне конвейера

Здесь живут инструменты, которые **не являются стадиями перевода** (стадии — в `cli/` и `web/`): браузерные юзерскрипты и их сборщик. Конвейер от них не зависит — `tools/` можно вынуть из репо, NovelMaestro заработает как раньше. Юзерскрипты сознательно живут в основном репо, а не в зеркалах/gist'ах: единый источник истины, code review и история версий в git вместо дропдауна версий.

## Что где лежит

| Путь | Что это | Зачем |
| --- | --- | --- |
| `build_userscripts.py` | сборщик юзерскриптов из частей | публикуемый скрипт обязан быть ОДНИМ файлом (менеджеры по расширению `.user.js` предлагают установку, каталоги тоже ждут один файл), а разрабатывается он по частям |
| `NovelMaestro_Lite/` | юзерскрипт-читалка NovelMaestro Lite | «прочитать главу здесь и сейчас» в браузере: лёгкий аналог конвейера без сервера и установки (перевод стримингом, глоссарий по книгам, NER); данные — в IndexedDB сайта книги, в файлы проекта ничего не пишется |
| `rulate_reload/` | юзерскрипт массового обновления глав | заливка переведённых глав и названий на tl.rulate.ru из локального `.txt` (паузы, проверка, dry-run) — руки прочь от ручного копирования сотен глав |

У каждого скрипта — свой `README.md` (установка, использование, настройки): [NovelMaestro_Lite](NovelMaestro_Lite/README.md), [rulate_reload](rulate_reload/README.md). Здесь — только общий обзор и сборка.

## Раскладка юзерскрипта

```text
tools/<скрипт>/
├── <имя>.user.js    # публикуемый файл: СОБРАННЫЙ, руками не правится
├── <имя>.meta.js    # собранный файл проверки обновлений: баннер без тела
├── meta.js          # баннер ==UserScript==, единственный источник @version
├── src/000-open.js  # открывающая строка IIFE-обёртки
├── src/NNN-….js     # части, уже на финальном отступе
├── src/900-close.js # закрывающая строка обёртки
└── README.md        # установка, формат файла, настройки
```

Порядок частей = порядок секций скрипта (часть шелла создаёт DOM-ссылки, «События» и «Инициализация» исполняются сразу — это функциональный инвариант, а не вкус); нумерация `NNN` с шагом 10, чтобы вставка части была новым файлом `025-*.js`, а не переименованием хвоста. Дробим только Lite (3,1 тыс. строк); rulate остаётся одной частью — 637 строк читаемы целиком.

## Сборка

Сборщик `build_userscripts.py` — сознательно тупая конкатенация: баннер, пустая строка, части в порядке имён; без переотступов, переносов и минификации. Единственные преобразования — CRLF→LF и подстановка `{{VERSION}}` из `@version` баннера. Благодаря этому собранный артефакт побайтово равен тому, что было бы написано руками, и `git diff` артефакта остаётся читаемым.

```bash
# из корня репо:
python3 tools/build_userscripts.py                   # пересобрать после правки в src/
python3 tools/build_userscripts.py --check           # артефакт == сборка? (гейт CI)
python3 tools/build_userscripts.py --check --node-check  # + синтаксис node --check
python3 tools/build_userscripts.py --list            # версии и число частей
```

Публикация и обновление (raw GitHub как основной путь, jsDelivr — зеркало с недельным кэшем, `@main` vs `@latest`, чистка кэша CDN, каталоги GreasyFork/GreasyArchive, неизменяемый `@namespace`) — в разделе «Юзерскрипты (tools/)» в [DEVELOPERS.md](../DEVELOPERS.md).

## Тесты

`python3 -m pytest tests/test_tools_userscripts.py -q` — артефакт и `.meta.js` побайтово равны сборке, части нумерованы и держат обёртку, версия берётся из `meta.js`, канон метаданных и ссылки установки, `node --check` по артефактам. Полный прогон `python3 -m pytest tests/ -q` — входной гейт перед коммитом (корневой AGENTS.md).
