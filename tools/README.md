# tools — вспомогательные утилиты вне конвейера

Здесь живут инструменты, которые **не являются стадиями перевода** (стадии — в `cli/` и `web/`): браузерные юзерскрипты, их сборщик и менеджер локальных библиотек SPA. Конвейер от них не зависит — `tools/` можно вынуть из репо, NovelMaestro заработает как раньше. Юзерскрипты сознательно живут в основном репо, а не в зеркалах/gist'ах: единый источник истины, code review и история версий в git вместо дропдауна версий.

## Что где лежит

| Путь | Что это | Зачем |
| --- | --- | --- |
| `build_userscripts.py` | сборщик юзерскриптов из частей | публикуемый скрипт обязан быть ОДНИМ файлом (менеджеры по расширению `.user.js` предлагают установку, каталоги тоже ждут один файл), а разрабатывается он по частям |
| `NovelMaestro_Lite/` | юзерскрипт-читалка NovelMaestro Lite | «прочитать главу здесь и сейчас» в браузере: лёгкий аналог конвейера без сервера и установки (перевод стримингом, глоссарий по книгам, NER); данные — в IndexedDB сайта книги, в файлы проекта ничего не пишется |
| `rulate_reload/` | юзерскрипт массового обновления глав | заливка переведённых глав и названий на tl.rulate.ru из локального `.txt` (паузы, проверка, dry-run) — руки прочь от ручного копирования сотен глав |
| `ui_probe.mjs` | обход SPA headless-браузером (`./dev.sh probe`) | поднимает сервер на временных данных (раздел TMP, фиктивные стадии вместо LLM), проходит все экраны, панели предпросмотра и модалки, затем сценарии (вложенная модалка, удаление с полем-паролем, Escape, создание проекта; страница «Настройки» — реестр пятью субвкладками (веб-сервер — последние блоки первой, а не отдельная вкладка), блок «Рассуждения модели», сохранение общих ключей в общий `.env` и маска секрета, локальная субвкладка «Внешний вид» без полей реестра и без «Сохранить»; «Запуски» — одна форма на стадию, «Сбросить настройки (N)» возвращает поля к значениям конфига); `pageerror`/`console.error`/5xx/битые ссылки — проблемы, скриншоты в `logs/ui_probe/`; playwright в зависимости не вводится — стоит глобально |
| `vendor_assets.py` | манифест локальных библиотек SPA | интерфейс обязан работать офлайн: версии, лицензии и sha256 каждого файла `web/static/vendor/` учтены, а `check` не даёт протащить CDN в `index.html` и молча подменить байт |

У каждого скрипта — свой `README.md` (пользовательское описание и установка) и `DEVELOPERS.md` (техническая документация): [NovelMaestro_Lite](NovelMaestro_Lite/README.md), [rulate_reload](rulate_reload/README.md). Здесь — только общий обзор и сборка.

## Раскладка юзерскрипта

```text
tools/<скрипт>/
├── <имя>.user.js    # публикуемый файл: СОБРАННЫЙ, руками не правится
├── <имя>.meta.js    # собранный файл проверки обновлений: баннер без тела
├── meta.js          # баннер ==UserScript==, единственный источник @version
├── src/000-open.js  # открывающая строка IIFE-обёртки
├── src/NNN-….js     # части, уже на финальном отступе
├── src/900-close.js # закрывающая строка обёртки
└── README.md        # установка, формат файла, настройки
```

Порядок частей = порядок секций скрипта (часть шелла создаёт DOM-ссылки, «События» и «Инициализация» исполняются сразу — это функциональный инвариант, а не вкус); нумерация `NNN` с шагом 10, чтобы вставка части была новым файлом `025-*.js`, а не переименованием хвоста. Дробим только Lite (3,1 тыс. строк); rulate остаётся одной частью — 637 строк читаемы целиком.

## Сборка

Сборщик `build_userscripts.py` — сознательно тупая конкатенация: баннер, пустая строка, части в порядке имён; без переотступов, переносов и минификации. Единственные преобразования — CRLF→LF и подстановка `{{VERSION}}` из `@version` баннера. Благодаря этому собранный артефакт побайтово равен тому, что было бы написано руками, и `git diff` артефакта остаётся читаемым.

```bash
# из корня репо:
python3 tools/build_userscripts.py                   # пересобрать после правки в src/
python3 tools/build_userscripts.py --check           # артефакт == сборка? (гейт CI)
python3 tools/build_userscripts.py --check --node-check  # + синтаксис node --check
python3 tools/build_userscripts.py --list            # версии и число частей
```

Публикация и обновление (raw GitHub как основной путь, jsDelivr — зеркало с недельным кэшем, `@main` vs `@latest`, чистка кэша CDN, каталоги GreasyFork/GreasyArchive, неизменяемый `@namespace`) — в разделе «Юзерскрипты (tools/)» в [DEVELOPERS.md](../DEVELOPERS.md).

## Тесты

`python3 -m pytest tests/test_tools_userscripts.py -q` — артефакт и `.meta.js` побайтово равны сборке, части нумерованы и держат обёртку, версия берётся из `meta.js`, канон метаданных и ссылки установки, `node --check` по артефактам. Полный прогон `python3 -m pytest tests/ -q` — входной гейт перед коммитом (корневой AGENTS.md).

## vendor_assets.py — локальные библиотеки SPA

Интерфейс обязан работать без сети, поэтому все сторонние JS-библиотеки лежат в `web/static/vendor/` и раздаются сервером; внешних `src`/`href` в SPA быть не может. Манифест `web/static/vendor/vendor.lock.json` — единственный источник истины о версиях: имя, пакет, версия, лицензия, homepage, происхождение (`url` или `bundle`), sha256 и размер каждого файла.

```bash
python3 tools/vendor_assets.py check   # гейт (CI): файлы == манифест, SPA офлайн
python3 tools/vendor_assets.py list    # что вендорится и каких версий
python3 tools/vendor_assets.py lock    # пересписать манифест по факту
python3 tools/vendor_assets.py fetch --name marked [--version 12.0.2] [--yes]
```

`check` ничего не качает и не меняет: он сверяет хэши и размеры, требует подписи каждой записи и отсутствия в `index.html` ссылок на CDN, и отдельным списком `RETIRED` не даёт вернуть удалённую библиотеку (Alpine.js удалён: SPA на ванильном JS). Остальные команды — инструменты разработки: `fetch` качает декларированный `url`, показывает расхождение хэша как смену версии и требует явного `--yes`; у самосборного бандла (`kind: bundle`) URL нет, он обновляется руками.
