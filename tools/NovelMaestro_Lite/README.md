# NovelMaestro Lite — юзерскрипт-переводчик

Лёгкий браузерный аналог конвейера NovelMaestro: юзерскрипт для Tampermonkey/Violentmonkey, который переводит страницы веб-новелл (и вообще любых сайтов) на русский язык через [OI]-совместимые LLM-серверы — прямо в браузере, без сервера и установки проекта. Глоссарий терминов ведётся по книгам, извлечение терминов (NER) и перевод — со стримингом.

Файл: `NovelMaestro_Lite_tampermonkey.js` (версия — в метаданных файла).

## Возможности

- **Перевод страницы** — текст главы извлекается по эвристикам (распространённые селекторы ридеров), делится на чанки по абзацам (`chunkSize`, СИМВОЛЫ) и переводится стримингом с отображением прогресса; результат рендерится прямо в содержимое страницы. Зависание LLM-сервера лечится **таймаутом зависания** (`requestTimeout`, по умолчанию 30000 мс): для обычного запроса это общий лимит времени, для стриминга — пауза без единого полученного символа; по нему запрос повторяется (число повторов — `maxRetries`), на прогрессбаре повторная попытка подсвечена оранжевыми полосами, незаконченный чанк переводится заново. Отмена перевода — кнопкой на панели (будит и зависший поток).
- **Глоссарий по книгам** — книга определяется по URL (поддерживается ручная привязка страницы к книге: URL без номера главы + название). Для каждой книги свой глоссарий (термин, перевод, тип, счётчик частоты), плюс отдельный **глобальный глоссарий**. В перевод подставляются только релевантные термины (нечёткий поиск по n-граммам, порог настраивается).
- **Типы и пол — в формате конвейера** — пол живёт внутри поля `type`: `Person (male)`, `Creature (female)`, `Person (unknown)` (как в `ner.json` полного конвейера и `core/common.py::collect_gender_names`). Типы не захардкожены: поле ввода свободное с подсказками (datalist) из канонических примеров и типов, реально присутствующих в глоссарии; записи LLM с неизвестными типами сохраняются как есть.
- **Извлечение терминов (NER)** — LLM находит имена/места/артефакты/организации на странице и пополняет глоссарий; повторное извлечение той же страницы пропускается (кэш, отключается). Дедупликация — точное совпадение, затем нечёткое; частоты суммируются. Извлечение идёт стримингом с отдельным прогресс-баром: ожидаемый размер ответа с терминами оценивается эвристически как ~2× размера исходного чанка (чанк — примерно половина ожидаемого ответа), процент считается по символам, полученным от LLM.
- **Настройки** — API Host/Key/модель (совместимо с OpenAI `/chat/completions`), уровень reasoning (пусто или `None` — параметр не передаётся), таймаут зависания (0 = без него), ретраи (сетевые ошибки, таймауты и зависание стриминга; HTTP 4xx/5xx не ретраятся), чекбокс «🖥️ Локальная модель без API-ключа» (пустой ключ разрешён, заголовок `Authorization` не отправляется вовсе), исходный/целевой язык, размер чанка, источник глоссария при переводе (книга или глобальный), редактируемые промпты перевода и извлечения. **Настройки сохраняются автоматически при каждом изменении** — кнопки сохранения нет, есть только сброс к значениям по умолчанию.
- **Запросы через `GM_xmlhttpRequest`** — обходят CORS и Mixed Content (http-API с https-страницы); при отсутствии `GM_xmlhttpRequest` — автоматический fallback на обычный `fetch`. Если менеджер скриптов не поддерживает стриминговый `responseType`, ответ приходит целиком и обрабатывается как один кусок потока. «Проверить сервер» показывает текст ошибки API и превью ответа, а не безымянное «Некорректный ответ API».
- **Импорт/экспорт** — глоссария и полного бэкапа всех данных (книги, глоссарии, кэш NER, настройки) — для переноса на другой компьютер. Импорт принимает оба формата: канон `ner.json` конвейера (JSON-список записей, лишние поля проекта сохраняются) и старый экспорт Lite (JSON-объект; отдельное поле `gender` из старых версий мигрирует в `type`, enum-типы `character`/`location`/… нормализуются в `Person`/`Location`/…).
- UI — во всплывающем окне (Shadow DOM, не зависит от стилей сайта): плавающие кнопки 🌐 и ⚙️ внизу справа.

## Установка

1. Установите расширение **Tampermonkey** (Chrome/Firefox/Edge) или Violentmonkey.
2. Откройте панель расширения → «Создать новый скрипт».
3. Вставьте содержимое `tools/NovelMaestro_Lite/NovelMaestro_Lite_tampermonkey.js` целиком и сохраните (Ctrl+S).
4. Откройте любую страницу — внизу справа появятся кнопки 🌐 (перевести) и ⚙️ (настройки).
5. **Разрешения на запросы к API (Tampermonkey)**: при первом запросе Tampermonkey спросит, разрешить ли междоменный запрос к домену вашего LLM-сервера — ответьте «Разрешить всегда». Если окно уже отклоняли или запросы молча не доходят (мгновенное «Некорректный ответ API»/«Failed to fetch»), откройте панель Tampermonkey → настройки скрипта NovelMaestro Lite → секция **«Безопасность XHR»** (`XHR Security`/«Безопасность»): добавьте домен API-хоста в список разрешённых (или выберите «Разрешить все домены» — скрипт объявляет `@connect *`). Без этого разрешения `GM_xmlhttpRequest` не выполнится и перевод работать не будет.

## Первый запуск

1. Откройте ⚙️ → вкладка **Настройки** → укажите **API Host**, **API Key** и **модель** (для локального сервера без ключа — включите «Локальная модель без API-ключа»); «Проверить сервер» покажет доступность и пинг (при ошибке — текст ошибки API и превью ответа сервера). Скрипт работает с любым OI-совместимым сервером (в т.ч. тем же, что настроен в системном `.env` NovelMaestro). Настройки сохраняются сами — достаточно поменять поле.
2. Откройте страницу главы. Кнопка 🌐 при непривязанном URL откроет модал «Определение книги» — укажите URL книги (без номера главы, кнопка «Авто» подставит автоматически) и название.
3. Перевод: 🌐 на странице главы. При включённом авто-NER термины сначала извлекутся в глоссарий книги (один раз на страницу), затем глава переводится по чанкам со стримингом.
4. Глоссарий: вкладка **Глоссарий** — добавление, правка, фильтр, сортировка по любому полю, пагинация, импорт/экспорт, очистка. Переключатель «Работать с» выбирает глобальный глоссарий или глоссарий конкретной книги.

## Формат глоссария

JSON-объект «идентификатор → запись», совместимый по полям записей с `ner.json` проекта NovelMaestro (у конвейера файл — JSON-список, при импорте в Lite он разворачивается в объект): пол указывается внутри `type` в скобках — `Person (male)`, `Person (female)`, `Person (unknown)`; для не-персонажей пол не указывается:

```json
{
  "ид_термина": {
    "term": "林浩",
    "translation": "Линь Хао",
    "type": "Person (male)",
    "count": 12
  }
}
```

Экспорт (кнопка «📤 Экспорт») выгружает глоссарий в JSON-список записей — тот же формат, что и `ner.json` конвейера, поэтому файл можно переименовать и положить в проект как есть.

Миграция: записи старых версий Lite с отдельным полем `gender` (`male`/`female`/`neutral`/`null`) автоматически конвертируются в `type` при загрузке скрипта и при импорте; `character` → `Person`, `location` → `Location` и т.д.

## Отличие от полного конвейера

NovelMaestro Lite — про «прочитать главу прямо сейчас»: перевод живёт на странице, ничего не сохраняется в файлы. Полный конвейер (epub → ner → ner_check → pipeline → translate_check → compile → wiki) — в web-интерфейсе проекта. Глоссарий Lite экспортируется в JSON и совместим по формату записей с `ner.json`, поэтому накопленное можно переносить в проект.

## Безопасность

- API Key хранится только в хранилище расширения (`GM_setValue`) и отправляется лишь на указанный API Host. Скрипт запрашивает `@match *://*/*` (универсальный переводчик) и `@connect *` (запросы к любому LLM-серверу; конкретные домены разрешаются в секции «Безопасность XHR» настроек скрипта в Tampermonkey) — при желании сузьте оба списка в метаданных до сайтов и хостов, которыми пользуетесь.
- Полный бэкап (`novelmaestro-backup-*.json`) содержит API Key — не публикуйте его.
